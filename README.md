### Project Description
This project demonstrates client-side scripting using JSON, modern JavaScript, and jQuery.

### Lab Activities

**Question 1: Create and Structure JSON Data**
- Created a JSON file named `books.json`.
- Stored information about two books using objects, properties, and arrays.
- Validated the JSON structure.

**Question 2: Retrieve and Display JSON Data**
- Created `books.html`.
- Used the JavaScript fetch() API to retrieve data from `books.json`.
- Displayed book titles, author information, and genres on a webpage.
- Implemented error handling using try/catch.

**Question 3: Compare Native JavaScript and jQuery**
- Created `jquery-dom.html`.
- Used jQuery 4.0.0 to modify text, add a CSS class, and handle button click events.
- Implemented the `.text()`, `.addClass()`, and `.on()` methods.

### Project Files
- `books.json` – JSON dataset containing information about two books.
- `books.html` – Webpage that retrieves and displays JSON data.
- `jquery-dom.html` – Webpage demonstrating jQuery DOM manipulation and events.
- `screenshots/` – Screenshots of the completed lab activities.

### How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install and enable the Live Server extension.
4. Right-click `books.html` and select Open with Live Server.
5. To test Question 3, open `jquery-dom.html` using Live Server.
6. Ensure an internet connection is available for loading the jQuery CDN.
